### Infrastructure

- cell tower
- Wi-Fi access point (for assisted positioning data)
- LEO (Low-Earth Orbit) SOS satellites (e.g., Globalstar) - ~1,414 km
- LEO (Low-Earth Orbit) internet/cellular satellites (e.g., Starlink Direct-to-Cell) - ~550 km
- MEO (Medium-Earth Orbit) GPS navigation satellites - ~20,200 km
- MEO (Medium-Earth Orbit) Galileo navigation satellites - ~23,222 km
