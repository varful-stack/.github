# Varful

A safer, funnier, and more social hiking experience in Romania.

The project already exists. This organization is an extension module that will be built on top of the existing codebase.

Everything newly created here is, in fact, part of my bachelor's degree.

See [documentation](https://github.com/varful-stack/.github).

## Short Term (Thesis) Target

Enhance and maintain the current codebase by:

- adding new functionalities (security, statistics, community)
- fixing spaghetti code (normalize database schema, respect SoC, DRY, SRP)
- scaling our infrastructure (migrate our main server, use SOA architecture, build dedicated microservices)

## Long Term (in 1 Year) Target

Populate Romania's trail paths with Starlink dishes to maximize hiking safety.
